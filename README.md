# Charitize

Charitize is a modern charity and donation platform that connects donors with people in need through categorized donation cases and humanitarian volunteer events.

## Features

- Categorized donation cases
- Volunteer events and activities
- Secure payments with Stripe
- User dashboard
- Admin dashboard
- Responsive modern UI

## Technologies Used

- Laravel
- PHP
- MySQL
- Bootstrap / Tailwind CSS
- JavaScript
- Stripe API
